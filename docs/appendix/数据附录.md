## D. 覆盖率交集（实测）

别名归一规则：`bash`→`shell`、`sh`/`zsh`→`shell`、`csharp`→`cs`、`cplusplus`→`cpp`、
`objective-c`→`objectivec`、`vbnet`/`vbscript`→`vba`、`dos`→`batch`、`x86asm`/`armasm`→`asm`、
`golang`→`go`、`proto`→`protobuf`、`h5`/`sgml`/`vue`→`html`、`svg`→`xml`，
repl 变体与 `plaintext`/`text` 不计入。

```
hljs(SiYuan) languages = 201
Magika labels          = 214
betlang labels         =  48

hljs covered by betlang = 46 (22.9%)
hljs covered by Magika  = 66 (32.8%)
hljs covered by neither = 127
```

### D-1. betlang 能覆盖的 46 种 hljs 语言

```

gradle groovy haskell ini java javascript json julia kotlin lisp lua markdown

typescript vbnet vbscript verilog x86asm xml yaml
```

### D-2. 只有 Magika 能覆盖的 20 种

```
autohotkey autoit awk coffeescript diff erb fortran handlebars latex makefile
matlab prolog protobuf scss smali solidity tcl twig vhdl wasm
```

> 这 20 种如果能用规则表覆盖，Magika 相对 betlang 的唯一优势就消失了。
> 其中 `diff` / `makefile` / `protobuf` / `wasm` / `erb` / `handlebars` / `scss` 都极易用规则识别。

## E. betlang slug → hljs 名称 映射（实现要用）

见 `06-插件设计方案.md` 第 5 节的完整 TypeScript 表格。
只有 5 个需要改名，其余同名：

| betlang | hljs |
|---|---|
| `cs` | `csharp` |
| `shell` | `bash`（hljs 里 bash/shell 都注册了） |
| `asm` | `x86asm`【待确认】 |
| `batch` | `dos` |
| `vba` | `vbnet`【待确认，另一个候选是 `vbscript`】 |

hljs 中**不存在**、因此必须在映射表里写 `null` 的 betlang 标签：

```
cobol gemfile gemspec
```
